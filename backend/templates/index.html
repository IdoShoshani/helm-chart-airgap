Package Helm Chart for Air-Gap

Full URL to the Helm repository
Full OCI registry URL (oci:// prefix required)
Provide custom values to override chart defaults. This helps discover the correct container images.
Maximum file size: 16MB
How it works
  1. Enter your Helm chart source (repository or OCI registry)
  2. Optionally provide values.yaml to customize the chart
  3. The tool will automatically:
    • Download the Helm chart and dependencies
    • Discover all container images referenced in the chart
    • Download all images
    • Package everything into a single bundle
  4. Download the bundle and transfer it to your air-gapped environment
