About Registry Credentials
  • Environment Variable credentials are configured in docker-compose.yml and are read-only in the UI
  • Web UI credentials can be added, edited, and deleted through this interface
  • Credentials are automatically used when packaging charts from private registries
  • Use the "Test" button to verify credentials work before packaging
Supported Registries

The following registries are commonly used and supported:

  • ghcr.io - GitHub Container Registry
  • quay.io - Quay.io / Red Hat Quay
  • docker.io - Docker Hub
  • gcr.io - Google Container Registry
  • registry.k8s.io - Kubernetes Registry
  • public.ecr.aws - AWS ECR Public
  • mcr.microsoft.com - Microsoft Container Registry
  • registry.redhat.io - Red Hat Container Registry
  • registry.gitlab.com - GitLab Container Registry
  • harbor.* - Harbor registries
  • nexus.* - Nexus registries
  • artifactory.* - Artifactory registries
  • Custom registries - Any OCI-compatible registry

Note: This application supports any OCI-compatible registry. For private registries, you'll need valid credentials. For public registries, credentials are optional unless rate limiting applies.
